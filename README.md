# scorpio-smartwatch
Open sourced smartwatch designed to track activities, and key biometrics. Includes GPS, motion sensors, heart rate and BLE. No subscription, no cloud.



### Component Breakdown (Subject to Change)
- MCU: NRF52840
- GPS: MIA-M10Q
- IMU: LSM6DSV80X
- MAG: LIS2MDL
- FLASH: ZDSD16GLGIAG
